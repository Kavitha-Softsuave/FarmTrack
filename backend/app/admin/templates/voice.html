How to generate the audio

  1. Put GOOGLE_TTS_API_KEY in the .env and set TTS_PROVIDER=google (steps: docs/voice-package.md).
  2. Run python scripts/generate_prompt_audio.py in the backend folder (--list-voices first checks that the voices exist).
  3. The app downloads the new audio the next time it is online (the catalogue version changes).
